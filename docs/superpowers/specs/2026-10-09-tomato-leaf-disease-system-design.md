# 番茄叶片病害识别系统设计规格

## 1. 项目定位

本项目是在现有 CIFAR-10 图像分类练习的基础上，独立开发一个面向课程大作业的番茄叶片病害识别系统。系统使用公开的 PlantVillage 数据集，以 SimpleCNN 为基线、ResNet18 迁移学习模型为主模型，提供可复现训练、独立测试、多指标比较、Grad-CAM 可解释结果和 Streamlit 中文网页演示。

项目目录固定为 `D:\人工智能\番茄叶片病害识别系统`。原项目 `D:\人工智能\4图像分类系统` 只作为实现风格参考，不修改其文件、数据或模型权重。

## 2. 目标与成功标准

### 2.1 目标

- 使用公开数据完成番茄叶片健康状态及病害类别的多分类。
- 建立 SimpleCNN 与 ResNet18 的公平对比实验。
- 生成可直接用于课程报告的真实指标、曲线、混淆矩阵和错误案例。
- 提供可以现场演示的 Streamlit 中文网页。
- 固化数据划分、类别映射、随机种子和训练配置，使实验可复现。

### 2.2 验收标准

- 数据准备脚本能从 PlantVillage 原始未增强数据中筛选所有番茄类别，并产生互不重叠的训练、验证、测试划分。
- SimpleCNN 与 ResNet18 均能完成训练、保存最优权重并在 CPU 上加载推理。
- 评估脚本只使用测试集生成最终指标，输出 Accuracy、Macro Precision、Macro Recall、Macro F1、分类报告和归一化混淆矩阵。
- 网页能上传 JPG、JPEG、PNG 图片，显示 Top-3 结果、置信度图和 Grad-CAM 叠加图。
- 缺少数据、权重、输出文件或上传无效图片时，系统给出清楚的中文提示。
- 自动化测试覆盖核心数据、模型、推理和解释接口，并通过一次 Streamlit 启动冒烟检查。

## 3. 范围边界

### 3.1 本期包含

- PlantVillage 番茄类别筛选与固定数据划分。
- 训练集数据增强，验证集和测试集确定性预处理。
- SimpleCNN 基线训练。
- ResNet18 两阶段迁移学习。
- 指标、训练曲线、混淆矩阵、错误样本与模型效率对比。
- 单图 Top-3 推理与 Grad-CAM。
- Streamlit 中文展示系统。
- README、依赖清单、忽略规则和测试。

### 3.2 本期不包含

- 目标检测、实例分割或视频实时检测。
- 手机端、微信小程序或云端部署。
- 在线数据库、用户账号或历史记录服务。
- 自动给出农药、剂量或治疗处方。

- ResNet50、ViT 等大模型的大规模调参。

## 4. 数据设计

### 4.1 数据来源

数据采用 PlantVillage 的原始未增强版本。完整数据集约 5.43 万张图片、38 个作物与病害组合类别；本项目只筛选类别名前缀为 `Tomato___` 的番茄图片。

数据来源与引用信息记录在 README：

- TensorFlow Datasets 目录：<https://github.com/tensorflow/datasets/blob/master/docs/catalog/plant_village.md>
- Mendeley 数据入口：<https://data.mendeley.com/datasets/tywbtsjrjv/1>

### 4.2 类别

系统使用 PlantVillage 番茄子集的 10 个类别：

1. 细菌性斑点病
2. 早疫病
3. 晚疫病
4. 叶霉病
5. 斑枯病
6. 二斑叶螨
7. 靶斑病
8. 黄化曲叶病毒病
9. 花叶病毒病
10. 健康叶片

代码内部保留原始英文目录名作为稳定类别标识，中文名称和简介由单独元数据文件映射，避免展示文本变化影响模型标签顺序。

### 4.3 划分与防泄漏

- 使用固定随机种子 42，按类别分层划分为 70% 训练集、15% 验证集、15% 测试集。
- 首次准备数据时生成包含相对路径、类别和划分的清单文件，后续训练直接复用，禁止每次启动重新随机划分。
- 划分前计算文件哈希并检测重复图片；相同内容不得跨越不同划分。
- 只使用未增强原图进行划分。旋转、翻转等在线增强仅作用于训练集。
- 测试集只用于最终评估，不参与模型选择、早停或阈值调整。

### 4.4 预处理与增强

- 所有模型接收 224×224 RGB 图片。
- 训练集采用适度的随机裁剪、水平翻转、小角度旋转和颜色扰动。
- 验证集、测试集和网页推理使用确定性的缩放、中心裁剪和归一化。
- ResNet18 使用与 ImageNet 预训练权重对应的归一化参数。
- SimpleCNN 使用同一训练、验证、测试划分；其归一化参数由配置固定，确保实验可复现。

### 5.1 模块职责

- `config.py`：集中定义路径、类别、随机种子、训练超参数和默认模型，不执行训练逻辑。
- `prepare_data.py`：扫描原始数据、筛选番茄类别、检测重复项并写出固定划分清单。
- `dataset.py`：依据清单构造 DataLoader，并分别提供训练与评估预处理。
- `models/`：通过统一构造接口返回模型和模型元数据。
- `train.py`：统一训练循环、早停、历史记录和最优检查点保存。
- `evaluate.py`：只读取测试集，生成指标文件和可视化图表。
- `predict.py`：提供与界面无关的单图预处理、Top-3 预测和耗时统计。
- `explain.py`：针对 ResNet18 生成 Grad-CAM 热力图；不支持的模型返回明确说明。
- `disease_info.py`：维护中文名称、简介和免责声明，不包含处方建议。
- `app.py`：只组织页面和调用服务接口，不复制训练、推理或解释逻辑。

### 5.2 数据流

训练流程：原始数据目录 → 数据检查与固定清单 → DataLoader → 模型训练 → 验证集选择最优权重 → 测试集最终评估 → 报告与图表。

网页流程：上传图片 → 文件校验与 RGB 转换 → 与训练一致的预处理 → ResNet18 推理 → Top-3 概率 → Grad-CAM → 中文结果页面。

## 6. 模型与训练设计

### 6.1 SimpleCNN 基线

- 采用多个卷积、批归一化、激活和池化模块。
- 分类头前使用自适应池化，避免全连接层依赖固定中间尺寸。
- 使用交叉熵损失、AdamW 优化器和学习率调度器。
- 与 ResNet18 使用相同数据划分和主要评价指标。

### 6.2 ResNet18 主模型

- 加载 ImageNet 预训练权重，替换最终分类层为 10 类输出。
- 阶段一冻结骨干网络，只训练新分类头。
- 阶段二解冻最后一个残差模块和分类头，使用更小学习率微调。
- 依据验证集 Macro-F1 保存最优检查点，并配置早停。
- 检查点同时保存模型权重、模型名称、类别顺序、预处理信息、训练配置、最佳轮次和最佳验证指标，避免只保存裸权重造成误配。

### 6.3 可复现性

- 固定 Python、NumPy、PyTorch 和 CUDA 随机种子。
- 记录 Python、PyTorch、torchvision、CUDA、设备名称和关键依赖版本。
- 每次训练创建独立运行目录，保存配置快照、CSV 历史、日志和检查点。
- 不覆盖既有实验；网页通过明确配置选择展示模型。

## 7. 评估与报告

测试集输出以下内容：

- Accuracy。
- Macro Precision、Macro Recall、Macro F1。
- 各类别 Precision、Recall、F1 和样本数。
- 原始与归一化混淆矩阵。
- 训练损失、验证损失、训练准确率、验证准确率和验证 Macro-F1 曲线。
- 模型参数量、权重文件大小、CPU 单图推理耗时；若有 CUDA，再附 GPU 耗时并注明设备。
- 置信度最高的正确样本、置信度最高的错误样本和最常见混淆类别。

模型比较必须使用同一测试划分。所有报告值由评估脚本产生，README 和课程报告不得提前写入假设准确率。

## 8. Streamlit 界面

### 8.1 首页

- 项目名称、课程项目定位与功能简介。
- 数据来源、支持类别和模型说明。
- 使用步骤、适用范围和免责声明。

### 8.2 叶片识别

- 接受单张 JPG、JPEG、PNG 图片。
- 显示上传原图、预测类别、主置信度和 Top-3 横向柱状图。
- 显示 Grad-CAM 原热力图或叠加图。
- 显示病害简介；不提供农药、剂量和治疗承诺。
- 当最高置信度低于配置阈值时，提示“模型把握较低，图片可能不属于训练分布”，仍保留概率结果供教学观察。

### 8.3 模型分析

- 读取已经生成的评估产物，不在网页访问期间重新训练或重新评估。
- 对比 SimpleCNN 与 ResNet18 的主要指标、参数量、模型大小和推理耗时。
- 展示训练曲线、混淆矩阵和错误案例。
- 若某项产物不存在，单独提示缺失项，不影响其他页面使用。

## 9. 异常与安全处理

- 数据目录不存在：提示用户运行数据准备命令并显示期望目录，不静默下载大文件。
- 类别不完整：列出缺失或多余类别并拒绝开始训练。
- 划分清单与文件不一致：中止训练，要求重新执行受控的数据准备。
- 权重不存在或元数据不匹配：网页提示先训练或选择正确检查点，禁止使用错误类别顺序继续预测。
- 上传文件损坏或格式不支持：捕获异常并显示中文错误，不输出内部堆栈。
- 灰度图、调色板图和带透明通道图片统一转换为 RGB。
- CUDA 不可用或显存不足：默认回退 CPU；训练发生显存不足时给出降低批量大小的提示，不自动改变实验参数。
- 所有用户路径均按本地文件处理，不执行上传文件中的任何内容。

## 10. 测试与验证

### 10.1 自动化测试

- 固定种子下的数据划分可复现、互不重叠且维持类别比例。
- 重复文件检测能阻止相同内容跨划分。
- 类别英文标识、索引和中文显示一一对应。
- 两个模型对模拟批次均输出正确的 10 类张量。
- 图片预处理支持 RGB、灰度和透明通道输入。
- Top-3 结果按概率降序排列，标签来自检查点类别映射。
- 权重缺失、损坏和类别不匹配时产生预期错误。
- Grad-CAM 输出尺寸正确且数值有限。
- 报告生成器能够在小型模拟数据上生成指标和混淆矩阵。

### 10.2 集成与人工验证

- 在 CPU 上用少量样本完成一次最小训练、保存、加载、评估、预测闭环。
- 执行 Python 编译检查和完整自动化测试。
- 启动 Streamlit 并完成首页、上传、预测和模型分析页面的冒烟验证。
- 用至少一张有效叶片图、一张灰度图、一张透明 PNG、一张损坏文件和一张非叶片图片进行人工检查。

## 12. 实施约束

- 优先使用项目内虚拟环境，但虚拟环境目录不进入版本控制。
- 数据集、模型权重、运行日志和生成图片默认不提交 Git，只提交必要的目录占位与说明。
- 训练参数通过配置或命令行显式指定，避免在多个脚本内重复硬编码。
- 第一版不增加数据库、登录、部署或实时摄像头功能。
- 在全部测试和真实命令输出完成前，不宣称项目已训练完成或指标达标。
